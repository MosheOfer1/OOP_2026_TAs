# OOP 2026 – TA Materials  
Welcome to the weekly code repository for our OOP 2026 tutorials — every week we’ll push the new lesson’s code right here.  
**Week 01 – Getting Started**  
**What we did:**  
• Introduced the course structure and main objectives (classes, objects, inheritance, polymorphism).  
• Set up the working environment: installed Python/Java, configured IDE, created project skeleton.  
• Wrote our first simple class: a “Person” with attributes (name, age) and methods (greet, displayInfo).  
• Demonstrated creating objects from that class and invoked methods to show basic behavior.  
• Discussed basic OOP vocabulary (class vs object, instance, method, attribute) and how we’ll apply it in coming weeks.  

**What to look at in the “TA1” folder:**  
• `Person.java` / `Person.py` – our first class implementation  
• `Main.java` / `main.py` – sample usage, creating instances and calling methods
